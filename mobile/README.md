# NiimFree (mobile)

A free, local-first, open-source client for **Niimbot** label printers. No account, no
cloud dependency, works offline. Built with **Expo + React Native + TypeScript**.

This is the real app (the `/project` folder one level up is the original Claude Design
prototype it was built from). Target hardware for this build: **B1 / B21 / B3S**.

## What works

- **Labels** home — recent grid, quick-starts, `New label` → editor. (SQLite-backed.)
- **Templates** — starter + your own, with editable fields highlighted; **Use → fill the
  blanks** with a live preview, including smart-date offset chips.
- **Label editor** — drag/resize elements on a canvas, insert text / shapes / images /
  dynamic dates (QR & barcode are visual placeholders for now — see below), contextual
  inspector, "mark as editable field" for templates.
- **Print** hub — Bluetooth connect/scan, live status (battery / lid / paper / RFID),
  density & quantity defaults, test print.
- **Preview** — true 1-bit "print output" render (what actually prints), density / quantity
  / rotation, size-mismatch warning, live print progress.
- **Feature A — label-size detection:** on connect the app reads the label's RFID one-code,
  looks it up in the local barcode→size table, and either auto-locks the size or asks once
  and remembers it forever. Manage remembered labels in Settings.
- **Feature B — templates with editable fields.** Filling a template never mutates it; it
  produces a new label.
- **Feature C — smart dates.** "Use by +N days" computed at print time.
- Light/dark themes, no-account/no-tracking by design.

## Requirements

- **Node.js 18+** and **Git**.
- A **Mac with Xcode** to build for iPhone (you mentioned you'll do this on your Mac).
- An **Apple ID** (a free one works for installing to your own device for 7 days; a paid
  Apple Developer account avoids the weekly re-sign).
- **Bluetooth needs a real device + a native build.** This app cannot run in **Expo Go**
  (Expo Go has no Bluetooth/native modules). Use a development build (below).

## Setup

```bash
cd mobile
npm install
# Align native module versions to your installed Expo SDK (recommended):
npx expo install --fix
```

## Run on your iPhone (recommended path on macOS)

Option A — local build with Xcode (no Expo account needed):

```bash
npx expo prebuild --clean         # generates the native ios/ project
npx expo run:ios --device         # pick your plugged-in iPhone
```

The first run opens Xcode signing — select your Apple ID team for the `com.niimfree.app`
target. After it installs once, day-to-day you can just run:

```bash
npx expo start --dev-client
```

and open the app on the phone (it connects to the Metro bundler).

Option B — EAS cloud build (no local Xcode build, needs a free Expo account):

```bash
npm i -g eas-cli
eas login
eas build --profile development --platform ios   # builds in the cloud, install via QR
npx expo start --dev-client
```

## Using it

1. **Print tab → Connect printer.** Turn the printer on, allow Bluetooth when prompted, pick
   it from the list.
2. Insert a label roll. If it's new, the **"New label detected"** sheet asks the size once;
   after that it auto-locks.
3. **Labels → New label** (or **Templates → Use**), design/fill, **Preview**, **Print**.
4. **Test print** on the Print tab prints a calibration pattern.

## Notes & known limitations

- **Printer protocol:** the print sequence follows the documented "B1" print task
  (B1/B21/B3S, 2024 firmware) from the NIIMBOT Community Wiki / niimbluelib. It was written
  without hardware in the loop, so the first thing to validate on your B1 is a **Test print**.
  If a model needs tweaks, the protocol lives in `src/lib/niimbot/` (`commands.ts` is the
  sequence, `encoder.ts` is the bitmap row format) and is small/commented.
- **QR codes & barcodes are real and scannable.** QR via `qrcode-generator`, 1D barcodes
  (Code 128 / EAN-13 / Code 39) via `jsbarcode`'s encoders — both painted to a crisp 1-bit
  PNG in `src/lib/codes.ts` so they rasterize and print exactly. Invalid content (e.g. a
  non-13-digit EAN) falls back to a placeholder tile in the editor.
- **App icon, adaptive icon, and splash** are generated by `scripts/gen-assets.js`
  (`node scripts/gen-assets.js`) into `assets/` and wired up in `app.json`. Re-run that script
  to regenerate them if you tweak the design, or drop in your own PNGs.
- If a native build fails on the New Architecture, set `"newArchEnabled": false` in
  `app.json` and rebuild.

## Project structure

```
app/                      Expo Router routes
  _layout.tsx             providers (theme, gesture, safe-area) + global overlays
  (tabs)/                 Labels / Templates / Print / Settings
  editor.tsx              full-screen label editor
  preview.tsx            1-bit print preview (modal)
src/
  theme/                  color tokens + ThemeProvider (light/dark)
  types/models.ts         data model (spec §8)
  data/presets.ts         label sizes, date presets, starter templates (seeded)
  lib/
    db.ts                 SQLite persistence
    niimbot/              packet framing, command builders, bitmap encoder, printer client
    ble/                  react-native-ble-plx transport
    raster.tsx            label → 1-bit raster (view-shot + Skia)
    labelValues.ts        template field resolution
    factory.ts            new design / label-from-template
  store/                  Zustand: printer, settings, session, toast
  components/             UI primitives, Icon, LabelView, sheets
```
