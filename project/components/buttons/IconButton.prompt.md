Icon-only button for toolbars, headers, and list rows. Always pass `label` for accessibility.

```jsx
<IconButton icon="arrow-left" label="Back" />
<IconButton icon="more-horizontal" variant="tonal" label="More" />
<IconButton icon="plus" variant="solid" label="Add" />
```

Variants: plain, tonal (soft surface), solid (primary). Sizes: sm (36), md (44).
